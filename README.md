# Net 급여 계산기

받고 싶은 **세후 실수령액**을 넣으면 4대보험·소득세(간이세액표)·지방소득세를 거꾸로 더해 **필요한 세전 급여**를 찾아 주는 계산기입니다.

- 배포 주소: https://net-salary-calculator-opal.vercel.app
- 구성: `index.html` 한 개 (HTML·CSS·JS 모두 들어 있고, 빌드 과정이나 외부 라이브러리 없음)

## 기능

- **월 / 연간** 실수령액 기준 탭
- 입력값: 목표 실수령액, 월 비과세액(식대 등, 기본 20만 원), 공제대상 가족 수(본인 포함), 그중 8~20세 자녀 수, 소득세 원천징수 비율(80% / 100% / 120%)
- 결과: 필요한 세전 급여(비과세 포함)와 항목별 공제 내역 (국민연금·건강보험·장기요양·고용보험·소득세·지방소득세)
- **두루누리 지원**(80%) 선택 시 국민연금·고용보험(실업급여)분 차감
- **회사 부담·총 인건비**: 사업장 규모(고용안정·직능 0.25~0.85%)와 산재 업종(2026년 고시 요율 + 출퇴근재해 0.06%)을 골라 사업주 부담분과 총 인건비 표시
- 같은 실수령액이 나오는 급여 범위가 1,000원 이상이면 상한도 안내
- 국민연금 상·하한 적용 시기 선택 (2026.1~6월 637만/40만, 2026.7월~ 659만/41만)
- 산재 업종 요율 직접 입력, 소득세가 나온 간이세액표 구간·열 표시, 세전 대비 공제율 표시
- **계산 기준 수정 가능**: 화면 아래 "계산 기준"에서 요율·상하한·자녀공제액을 바꿀 수 있고, "기본값으로 되돌리기"로 원래 값으로 돌아갑니다.

## 계산 방법

1. 세전 급여 `gross`를 넣으면 실수령액을 구하는 함수 `calc()`를 만듭니다.
2. `reverse()`에서 **이분 탐색**으로 근사값을 찾은 뒤, 그 아래 15만 원 범위를 1원 단위로 모두 계산해 `calc(gross).net >= 목표`를 만족하는 가장 작은 세전 급여를 고릅니다 (탐색 범위 0 ~ 20억 원).
   간이세액표가 계단식이라 급여가 10원 늘 때 실수령액이 오히려 줄어드는 구간이 있어서, 이분 탐색만으로는 최소값을 놓칠 수 있습니다(무작위 목표 3,000개 중 433개, 실측 최대 차이 약 5.3만 원).
3. 비과세분은 보험료와 소득세 계산에서 뺍니다 (과세 급여 = 세전 급여 − 비과세).
4. 모든 항목은 10원 미만을 버립니다.

## 계산 기준 (2026년 11월 기준 기본값)

| 항목 | 기준 |
|---|---|
| 국민연금 | 기준소득월액(1,000원 미만 절사)을 상한 659만 원 / 하한 41만 원으로 제한한 뒤 본인부담률 4.75% (요율 9.5%의 절반, 2026.7월~) |
| 건강보험 | 3.595% (7.19%의 절반) |
| 장기요양보험 | 건강보험료 × 0.9448 / 7.19 |
| 고용보험 | 0.9% |
| 소득세 | 소득세법 시행령 [별표 2] 근로소득 간이세액표 (2026.2.27. 개정, 2026.3.1. 이후 지급분). 원문 646개 구간을 그대로 조회 × 원천징수 비율 |
| ├ 월 1,000만 원 초과 | 별표 2 표 하단 산식 적용 |
| ├ 가족 11명 초과 | 별표 2 제4호: 11명 세액 − (10명 세액 − 11명 세액) × 초과 인원 |
| └ 8~20세 자녀 공제 | 1명 20,830원, 2명 45,830원, 3명 이상은 45,830원 + 2명을 넘는 1명당 33,330원 (별표 2 제3호) |
| 지방소득세 | 소득세 × 10% |

요율이나 간이세액표가 바뀌면 `index.html` 안의 `DEFAULTS` 객체와 간이세액표 데이터, 화면 하단 안내 문구를 함께 고쳐야 합니다.

### 엑셀 자료와 대조 (`data/` 폴더, GitHub에는 올리지 않음)

세후급여계산기 엑셀(2026, 역산 추가본)과 비교한 결과:

- 간이세액표 646개 구간과 1,000만 원 행: 앱 데이터와 완전히 같음
- 세후 2,000,000원 역산(식대 0, 가족 1명, 150인 미만, 산재 0.8%): 기본급 2,248,420원, 회사 부담 243,410원, 총 인건비 2,491,830원으로 엑셀과 같음
- 기본급 2,500,000원 정방향: 4대보험 242,920원, 소득세 35,600원, 지방소득세 3,560원, 실수령 2,217,920원, 회사 부담 270,670원으로 엑셀과 같음
- 다른 점: 엑셀의 국민연금 기준소득월액 상·하한은 637만 / 40만(2026.1~6월 값)이고, 앱은 기본으로 2026.7~ 값(659만 / 41만)을 씁니다. 화면에서 시기를 바꿀 수 있습니다.

### 공식 모의계산기와 대조 (2026-11-12)

4대사회보험 정보연계센터 모의계산(4insure.or.kr), 월 2,500,000원, 150인 미만:
국민연금 118,750 / 건강보험 89,870 / 장기요양 11,800 / 고용보험 22,500 (근로자 합계 242,920), 사업주 고용보험 28,750원 → 앱과 모두 같음.

장기요양보험은 **근로자 건강보험료 × (0.9448 ÷ 7.19)** 로 계산해야 공식 값과 맞습니다.
건강보험 총액에서 장기요양 총액을 구해 반으로 나누는 방식(참고한 다른 계산기 방식)은 이 경우 11,810원이 되어 10원 차이가 납니다.

## 실행과 배포

- 로컬에서 볼 때: `index.html`을 브라우저로 열면 됩니다.
- 배포: GitHub 저장소 `cho-kyeongseon/net-salary-calculator`가 Vercel 프로젝트와 연결되어 있어서, `main`에 푸시하면 프로덕션에 자동으로 다시 배포되고 다른 브랜치에 푸시하면 미리보기(preview) 배포가 만들어집니다.
